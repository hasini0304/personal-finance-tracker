# Pennywise – Personal Finance Tracker

Pennywise is a personal finance tracking web application that helps users manage their income and expenses, monitor spending patterns, and understand their monthly financial activity through interactive charts.

## Features

- Add income and expense transactions.
- Edit and delete existing transactions.
- Store transaction data using browser Local Storage.
- View total income, expenses, and balance.
- Filter dashboard totals and insights by month.
- Search transactions by description and category.
- Filter transactions by category and type.
- Set monthly budgets and month-specific savings goals.
- Review monthly spending insights and interactive charts.
- Import and export transactions as CSV.
- Generate due weekly or monthly recurring transactions when the app opens.
- Switch between light and dark themes.
- Responsive dashboard layout for desktop, tablet, and mobile.
- Supabase email/password sign-up, login, password recovery, and logout.
- Persistent Supabase sessions with the dashboard protected behind authentication.

## Tech Stack

- HTML
- CSS
- JavaScript
- Vite
- Chart.js
- Browser Local Storage
- Supabase Authentication

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hasini0304/personal-finance-tracker.git
```

### 2. Navigate to the project folder

```bash
cd personal-finance-tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use Pennywise.
